# Microserviço de Grade Curricular

Serviço Java para manter a grade curricular de uma escola, incluindo cursos e matérias. A estrutura separa entidades, repositórios, configuração de API e recursos versionados.

## Tecnologias principais

- Java
- Spring Boot
- Spring Data
- Maven
- Swagger/OpenAPI (configuração de documentação da API)

## Executar

Com JDK e Maven instalados:

```bash
./mvnw spring-boot:run
```

No Windows, use `mvnw.cmd spring-boot:run`. As configurações de conexão e execução estão em `src/main/resources`.

Este repositório é um serviço de backend. Não foi identificado um frontend correspondente na lista de projetos pessoais.
